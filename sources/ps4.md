# PlayStation 4

Suggest: RES=1920x1080 FPS=60
Status: reported -
Wake: press the PS button on the controller

- HDCP: Off (Settings › System › Enable HDCP, path from a third-party guide). With it on, game capture cards struggle.
- Audio Format (Priority): Linear PCM (Settings › Sound and Screen › Audio Output Settings › Audio Format (Priority)). Linear PCM is the default; the card takes PCM stereo, not bitstream.

## References

- [Sony PlayStation: How to change the audio output on PS4 consoles](https://www.playstation.com/en-us/support/hardware/ps4-change-audio-output/): Audio Output Settings path and Audio Format (Priority) with Linear PCM as default
- [Pushsquare: Guide: How to disable the PS4's HDCP encryption](https://pushsquare.com/news/2014/04/guide_how_to_disable_the_ps4s_hdcp_encryption) (third party): the Settings › System › Enable HDCP path, and that it blocked Elgato and Roxio capture cards
