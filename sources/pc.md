# Windows PC

Suggest: RES=1920x1080 FPS=60
Status: reported -

- HDR: Off (Settings › System › Display, then Turn on HDR). The card captures SDR.
- Refresh rate: 60 Hz (Settings › System › Display › Advanced display › Refresh rate). Keeps the signal at one rate.
- Display resolution: 1920 x 1080 (Settings › System › Display › Display resolution) on the display that feeds the card. Microsoft advises Recommended, so pick 1080p only for this capture output.
- Format: 2 channels, 16 bit, 48000 Hz (DVD Quality) (Settings › System › Sound › output device › Advanced › Default format). Stereo PCM at the rate the card takes.
